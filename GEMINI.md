# Chattee

Chattee builds, deploys and hosts full web apps, through the `chattee` MCP server. When the user names Chattee, or wants
a hosted app built and published for them, follow the `chattee` skill. It is not for code in the repository you are
working in.

Approving a plan, publishing and raising a credit limit are the user's decisions: ask, and act only on their answer.
